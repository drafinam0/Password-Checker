# 🛡️ Password Strength Checker (Pure Java + Cybersecurity Web UI)

A modern, cybersecurity-themed mini-project featuring a pure Java analysis backend and an ultra-modern, pure black cybersecurity dashboard interface.

---

## 🌟 Key Features

1. **Pure Java Password Analysis Engine**:
   - Zero third-party dependencies — built entirely using standard Java SE libraries (`java.lang.Character`, loops, `charAt()`, `com.sun.net.httpserver`).
   - Implements 5 security rules:
     - Minimum 8 characters in length
     - At least one uppercase letter (`A–Z`)
     - At least one lowercase letter (`a–z`)
     - At least one numeric digit (`0–9`)
     - At least one special character (`@, #, $, !, %, etc.`)
   - Strict score calculation: 1 point per rule (Max score: 5).
   - Dynamic classification:
     - **0 – 2**: `WEAK` (Red indicator)
     - **3 – 4**: `MEDIUM` (Amber/Orange indicator)
     - **5**: `STRONG` (Green indicator with shield activation)
   - Actionable missing-requirement suggestions generated by Java logic.
   - Common dictionary password detector (flags passwords like `password123`, `admin`, `12345678`).

2. **Ultra-Modern Cybersecurity Frontend**:
   - **Pure black background (`#000000`)** with glassmorphism cards and neon cyan, purple, and green glowing borders.
   - Show/Hide password toggle with interactive SVG eye icon.
   - Segmented 5-step visual strength meter with real-time color transitions.
   - Dynamic 5-rule checklist with green checks (`✓`) and red crosses (`✗`).
   - Warning banners for empty inputs and known weak passwords.
   - Real-time live synchronization toggle with the Java backend.

3. **Built-in Secure Password Generator**:
   - Cryptographically secure random password generator (`java.security.SecureRandom`).
   - Guaranteed 5/5 score meeting all 5 security criteria.
   - Adjustable length slider (8 to 28 characters).
   - One-click **Copy to Clipboard** with animated toast notification.
   - One-click **Test in Checker** to auto-populate and analyze.

4. **Multiple Execution Modes**:
   - **Modern Web Dashboard Mode**: Run `src.Main` to launch the embedded Java HTTP server on `http://localhost:8080/`.
   - **Terminal Console Mode**: Run `src.ConsoleApp` with interactive `Scanner` input.
   - **Automated Test Suite**: Run `test.TestRunner` for instant automated unit verification.

## 🔒 Privacy & Security Design
* **Zero Database Requirements**: No external database needed.
* **In-Memory Volatile Processing**: Passwords are processed strictly in RAM and immediately discarded.
* **Zero Logging**: Passwords are never written to logs, disk, or transmitted to third-party endpoints.
